# LibreTV Android TV 1.0.4 source

This branch contains the Android TV wrapper source and the LibreTV web application source used to produce its bundled UI.

- `tv-android/` contains the Android/Capacitor shell.
- `libretv-web/` contains the Next.js application source.

This is a source-only branch. APKs and generated web bundles are excluded. VOD defaults are empty; local live/VOD playlists, local environment files, standalone runtime configuration, signing keys, and passwords are not included. Configure providers privately for your own deployment.
